This repository contains laboratory assignments and experiments for CSE251 - Electronic Devices and Circuits Laboratory course. The labs focus on practical implementation and analysis of electronic circuits and devices.

## File Types
- `.raw` - Raw measurement data from laboratory instruments
- `.log` - Experiment log files with timestamps and measurements
- `.asc` - ASCII format data exports for analysis
- `.PNG` - Screenshots and graphs of experimental results

## Usage
Each lab folder contains:
1. Experimental data files
2. Analysis and processing files
3. Visual documentation (screenshots/graphs)
4. Task-specific implementations
