# Contributing Guidelines

## Academic Integrity Notice
This repository contains academic work for CSE251 - Electronic Devices and Circuits Laboratory at BRAC University. 

## Guidelines for Academic Use

### For Students
- This repository is shared for educational reference only
- Direct copying of solutions violates academic integrity policies
- Use this work to understand concepts and methodologies
- Always cite sources appropriately in your own work

### For Educators
- This work represents original student laboratory experiments
- May be used as reference for course development
- Please contact the author for permission before using in academic materials

### For Researchers
- Laboratory data and methodologies may be referenced with proper citation
- Contact author for detailed experimental procedures or raw data access

## Citation Format
If referencing this work, please use:
```
Alvie, M. H. U. K. (2023). CSE251 Lab Assignments - Electronic Devices and Circuits Laboratory. 
BRAC University. https://github.com/Nicgott99/CSE251-Lab-Assignment
```
